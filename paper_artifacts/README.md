# Paper artifacts

This compact folder contains only the lightweight artifacts most useful for a GitHub preview:

- Main PDF figures used in the paper.
- 5x5 beta-grid summary tables.
- Legacy 3x3 summary tables.
- A small subset of theory diagnostic summaries.

Large raw trajectories, full diagnostic trees, checkpoints, and gradient arrays are intentionally excluded. Use an external release/Zenodo archive for those files if exact full reproduction is required.
