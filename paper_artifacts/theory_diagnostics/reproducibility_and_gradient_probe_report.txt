REPRODUCIBILITY AND GRADIENT-PROBE REPORT
=========================================

This report describes the exact local experiment used for the gradient-probe
analysis reported below. The reported run is:

  validacion_teoria/descargas/adam_gradient_cifar10/runs/
  cifar10_tinycnn_adam_b1-0p9_b2-0p999_bs-128_grad-probe_seed-1234

The gradients analyzed here are probe gradients, not training minibatch
gradients. Adam updates the model with the train minibatch gradient; the saved
gradient at each iteration is the gradient of a fixed validation batch.

2. Dataset and split
--------------------

Dataset:
  CIFAR-10 from torchvision.datasets.CIFAR10.

Data root:
  validacion_teoria/descargas/data

Original CIFAR-10 train split:
  50,000 images, 10 classes.

Deterministic split:
  A torch.Generator with manual_seed(1234) was used to create a random

    First 5,000 indices of that permutation.

  transforms.ToTensor()
  transforms.Normalize(mean=(0.4914, 0.4822, 0.4465),
                       std=(0.2470, 0.2435, 0.2616))

Validation/probe transform:
  transforms.ToTensor()
  transforms.Normalize(mean=(0.4914, 0.4822, 0.4465),
                       std=(0.2470, 0.2435, 0.2616))

Important:
  The probe batch does not use data augmentation. The train batches do use data
  augmentation. The probe gradient is also computed with model.eval(), so the
  probe pass does not update BatchNorm running statistics.

6. Probe-gradient saving protocol
---------------------------------

At each training iteration k:

  1. A train minibatch is sampled from the train DataLoader. The model is in
     train mode, so train augmentation is active and BatchNorm running
     statistics are updated in the usual training way.

  2. The train minibatch forward pass is computed.

  3. The train loss is computed using cross entropy.

  4. Backward is called. At this point, model.parameters() contain the train
     gradients that Adam will use.

  5. These train gradients are cloned temporarily.

  6. optimizer.zero_grad(set_to_none=True) is called.

  7. The fixed probe batch is evaluated. The fixed probe batch is the first
     batch of the deterministic validation DataLoader. It has 128 images, no
     data augmentation, and is always the same batch throughout the run.

  8. The probe forward/backward pass is performed with model.eval(). Therefore,
     the probe pass does not modify BatchNorm running statistics.

  9. The probe gradient is flattened by iterating over model.parameters() in
     PyTorch order. The parameter-to-coordinate map is stored in:

       param_metadata.json

 10. The flattened probe gradient is computed in float32, cast to float16, and
     written as row k of:

       gradients.npy

 11. The cloned train gradients are restored.

 12. optimizer.step() is called. Thus Adam updates the model using the train
     minibatch gradient, not the probe gradient.

The saved gradient matrix has:
  shape = (7040, 24458)
  dtype = float16
  rows  = training iterations
  cols  = flattened trainable parameters

Total number of saved gradient entries:
  7040 * 24458 = 172,184,320

Important precision note:
  All analyses below are performed on the saved float16 gradient matrix. Thus
  "exactly zero" means exactly zero after storage in float16. The gradient was
  originally formed in float32 before being cast to float16.


7. Exactly zero gradients
-------------------------

Question:
  In the saved probe-gradient matrix, how many entries are exactly zero?

Method:
  Load gradients.npy using numpy.load(..., mmap_mode="r") and count exact
  equality to zero by row blocks:

    count += np.count_nonzero(block == 0)

Result:
  shape = (7040, 24458)
  dtype = float16
  total entries = 172,184,320
  exact zeros = 328

Relative frequency:
  zero_fraction = 328 / 172,184,320
                = 0.000001904935

  zero_percent  = 0.000190494 %

Equivalently:
  zero_fraction is approximately 1.9 * 10^(-6), i.e. about 2 / 10^6.

Conclusion:
  Exact zeros are negligible for the sign and log-magnitude analyses.


8. Constant-sign windows and magnitude-ratio condition
------------------------------------------------------

For a window width w and a start index k, consider the sequence:

  g_{k,i}, g_{k+1,i}, ..., g_{k+w-1,i}

for each coordinate i of the flattened probe gradient.

Condition A: constant sign
  A case (k, i) is counted as constant-sign if all w values are nonzero and
  have the same sign. If any value is zero or if the sign changes, the case
  fails Condition A.

Condition B: bounded magnitude ratio
  Among the cases satisfying Condition A, define:

    ratio_{k,i,w} = max_t |g_{k+t,i}| / min_t |g_{k+t,i}|,  t = 0,...,w-1

  Condition B is:

    ratio_{k,i,w} < sqrt(2)

The table reports:
  Row 1: percentage of all cases satisfying Condition A.
  Row 2: percentage satisfying Condition B among those already satisfying A.
  Row 3: percentage of all cases satisfying both A and B.

The window is moved across all admissible time positions k. For a given w,
there are (7040 - w + 1) time windows, and each is evaluated over all 24,458
gradient coordinates.

Table, reported for w = 2,...,6:

  metric                                                        w=2        w=3        w=4        w=5        w=6
  ----------------------------------------------------------------------------------------------------------------
  % constant sign                                               92.7321    85.7888    79.1238    72.7588    66.7297
  % ratio < sqrt(2) | constant sign                             67.6502    47.4627    34.4815    25.0421    18.0835
  % total satisfying both                                       62.7335    40.7177    27.2831    18.2203    12.0671

9. Consecutive log-gradient change Delta
----------------------------------------

For consecutive same-sign nonzero pairs, define:

  Delta_{k,i} = log |g_{k+1,i}| - log |g_{k,i}|

This is computed only when g_{k,i} and g_{k+1,i} are both nonzero and have the
same sign. Otherwise the pair is excluded.

Total possible consecutive cases:
  (7040 - 1) * 24458 = 172,159,862

Valid same-sign nonzero cases:
  159,647,370

Valid percentage:
  92.7320504009 %

Exact streaming statistics over all valid Delta values:
  mean = 0.0006649673
  std  = 0.6775685383
  min  = -13.5733070374
  max  = 13.9229555130

Signs of Delta:
  Delta > 0: 79,928,989 cases = 50.0659603725 %
  Delta < 0: 79,541,693 cases = 49.8233657091 %
  Delta = 0:    176,688 cases =  0.1106739184 %

Small-change thresholds:
  log(sqrt(2)) = 0.3465735903
  log(2)       = 0.6931471806
  log(1.1)     = 0.0953101798

Exact counts:
  |Delta| < log(sqrt(2)):
    108,001,835 cases = 67.6502437842 % of valid same-sign pairs

  |Delta| < log(2):
    135,906,472 cases = 85.1291643577 % of valid same-sign pairs

  |Delta| < log(1.1):
     44,400,103 cases = 27.8113588717 % of valid same-sign pairs

Interpretation:
  Delta is strongly centered near zero. Its exact mean is 0.000665, and the
  positive/negative split is almost exactly balanced. More than two thirds of
  same-sign consecutive pairs change magnitude by less than a factor sqrt(2),
  and more than 85% change by less than a factor 2.
